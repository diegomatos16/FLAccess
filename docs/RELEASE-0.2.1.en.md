# FLAccess 0.2.1 — Football Life 27

This release includes the 0.2.1 revisions through 0.2.1.35 (build 87). Football Life 27 support remains experimental.

- Updated menu and list reading. Master League Game Plan uses the game's current selection and announces the section when switching between starters and substitutes.
- Standings can read the selected club and its statistics directly from the game's table while the visible rows update.
- The FLAccess overlay groups speech, announcements, and accessibility sounds. It offers rate, pitch, volume, and voice settings, previews with 5, per-sound volume, and adjustable ball radar cadence.
- Ball holder changes can be announced with an adjustable interval and optional shirt number. Substitutions are announced for either team, and P or Select reads time and score while paused.

D-pad navigation through the full standings table still needs in-game verification. Slowdowns have been reported in lists and screen transitions.

Download FlAccess.zip and follow the guide in the sider folder. Compatible runtime DLLs are included, and SHA256SUMS.txt is available as a separate release asset.
