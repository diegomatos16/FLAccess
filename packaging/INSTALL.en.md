# Installing PES A11y Menu Scanner 0.1.4

1. Close the game and Sider.
2. Back up the installation's `SiderAddons` directory.
3. Merge this package's `SiderAddons` directory into the existing one.
4. Add the line from `sider.ini.snippet` to the `[sider]` section of your `sider.ini`.
5. Start the game normally with Sider and keep NVDA running.

Do not replace your complete `sider.ini`. The Lua module starts the Prism bridge automatically.

Compatibility: experimental build made for the studied `FL_2026.exe`. See `docs/README.en.md` for limitations and recovery.
