# FLAccess 0.2.1

FLAccess adds screen reader support and accessibility sounds to Football Life on Windows. Football Life 27 support is experimental.

- [Download FLAccess 0.2.1](https://github.com/diegomatos16/FLAccess/releases/tag/v0.2.1)
- [Instalação em português](packaging/INSTALL.pt-BR.md)
- [English installation guide](packaging/INSTALL.en.md)
- [Notas da versão](docs/RELEASE-0.2.1.pt-BR.md)
- [Release notes](docs/RELEASE-0.2.1.en.md)
- [Changelog](CHANGELOG.md)

Use the game controls to navigate. I and K or the right stick explore fields. In the pause menu, P or Select reads time and score. Use the FLAccess overlay to configure speech, announcements, and accessibility sounds.
