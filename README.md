# FLAccess

Current release: **0.1.9 — experimental**.

Screen-reader accessibility for SP Football Life2026/PES2021 through native game
text, focus, Sider and Prism, without OCR. This release also includes optional
experimental match audio through FlAccessGameplay. The two modules are independent.

- [Download 0.1.9](https://github.com/diegomatos16/FLAccess/releases/tag/v0.1.9)
- [Português: instalação, controles e limites](docs/README.pt-BR.md)
- [English: installation, controls and limitations](docs/README.en.md)
- [Todas as mudanças e pendências da 0.1.9](docs/RELEASE-0.1.9.pt-BR.md)
- [Changelog](CHANGELOG.md)

FlAccess.zip has three root folders: livecpk, modules and sider. It includes the
compatible modified Sider 7.3.3 DLL, Prism/OpenAL libraries and their notices.
Read installation instructions before migrating from the former FLAccess.lua.
WAVs are editable. FL 27 compatibility has not been established.

Game Plan player/attribute reading, useful-text review and shared reading paths
have improved. Rapid navigation, countries, first-menu choice, messages and some
tables/tooltips still have open reports. Gameplay audio/camera orientation is
experimental; this is not complete match accessibility. See release notes.
