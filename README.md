# FLAccess

Current release: **0.1.8** (experimental).

Menu accessibility for SP Football Life 2026 / PES 2021, using native game text
and focus through Sider and [Prism](https://github.com/ethindp/prism), without OCR.
Supports screen readers such as NVDA, with SAPI fallback.

- [Download 0.1.8](https://github.com/diegomatos16/FLAccess/releases/tag/v0.1.8)
- [Português: instalação, teclas e limitações](docs/README.pt-BR.md)
- [English: installation, controls and limitations](docs/README.en.md)
- [Notas da versão](docs/RELEASE-0.1.8.pt-BR.md)
- [Changelog](CHANGELOG.md)

This is experimental menu accessibility, not complete gameplay access. Known
reports remain open. The installer includes the compatible modified Sider DLL; see the
installation instructions and `sider-core/README.md`.

Release policy: always include the compatible Sider and Prism DLLs. See [publication guide](docs/PUBLICACAO.pt-BR.md).
